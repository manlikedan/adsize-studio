# adsize-studio

Streamlit app for resizing product image zips into Google Ads-ready asset sizes.

## Streamlit Cloud setup

- Repository: `manlikedan/adsize-studio`
- Branch: `main`
- Main file path: `app.py`
- Python version: `3.12`

Use Streamlit Cloud's **Advanced settings** to choose Python 3.12 when deploying. The AI background remover uses `rembg`, which is much safer on a stable Python release than on newly rolled-out Python versions.
